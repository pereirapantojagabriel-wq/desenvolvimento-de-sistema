Resumo do Sistema:

O sistema é uma plataforma completa para cadastro, divulgação e gerenciamento de vagas de Estágio e Jovem Aprendiz. Conecta estudantes a oportunidades reais de trabalho, permitindo que candidatos encontrem vagas, façam inscrições com 1 clique e acompanhem seu status em tempo real. Empresas e administradores contam com um painel completo para publicar novas oportunidades, gerenciar prazos, avaliar perfis de estudantes e deferir ou indeferir candidaturas.

O que é esta tela / Funcionamento:

Interface para entrada no sistema com credenciais de e-mail e senha. Permite acesso seguro tanto para estudantes quanto para empresas, gerando token JWT de sessão e redirecionando automaticamente para o painel correspondente ao tipo de usuário.

  • RNF01: Comparação segura de hash via biblioteca bcryptjs.
  • RNF03: Autenticação stateless via JSON Web Token (JWT) e cookies seguros.

Módulo: Segurança & Autoatendimento

Redefinição de Credenciais
O que é esta tela / Funcionamento:

Módulo em duas etapas para recuperação de conta. O usuário digita seu e-mail, recebe um código de validação de 6 dígitos e realiza a troca da senha com hash seguro imediato no banco de dados.

Recursos Técnicos & Requisitos Atendidos:
  • Autoatendimento: Redefinição segura sem necessidade de intervenção do administrador.
  • Criptografia: Nova senha imediatamente protegida por salt rounds no SQLite.
